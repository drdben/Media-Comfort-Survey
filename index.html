Response files

Each participant downloads a JSON response file containing their name and answers. Import the files here to combine them into one CSV spreadsheet. Processing happens in this browser.

Set up your clips

Edit clips.json in the survey folder before sharing this survey. Add one item per clip, with a unique id, title, optional content note, and a YouTube or Reddit URL. See the README for examples and embedding details.
